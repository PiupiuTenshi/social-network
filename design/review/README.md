# Hồ sơ duyệt thiết kế

- `approval-status.yaml`: trạng thái khóa hiện tại, 47/47 màn hình approved.
- `FINAL_REVIEW_GALLERY_STANDALONE.html`: gallery cuối, nhúng ảnh trực tiếp và mở ngoại tuyến.

Không dùng tệp trong `history/` làm nguồn triển khai Frontend.
